# Engineering journal

Keep one dated file per major case study, e.g. `2026-11-05-dynamo.md`. The goal is to practice judgment, not to reproduce a summary.

## Entry template

```markdown
# [Case study] — YYYY-MM-DD

## What I learned
-

## What surprised me
-

## What I would design differently
- Given these assumptions:
- I would change:
- Expected benefit:
- New cost or failure mode:

## My model of the system
<!-- Sketch data path, control path, and one failure path. -->

## Evidence and open questions
- Source:
- Claim it supports:
- Question I still have:
```

Write your first design before reading the historical solution when the chapter invites a design exercise. Afterward, note which constraint you missed and whether the historical choice still makes sense under your assumed workload.
